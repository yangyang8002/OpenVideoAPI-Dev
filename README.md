# OpenVideoAPI-Dev

The **plugin development environment** for OpenVideoAPI. Clone this repo and start writing plugins right away — no manual server setup, no npm publishing required, and code changes hot-reload automatically.

English | [中文](README.cn.md)

## Quick Start

```bash
npm run setup          # Clone server code into server/ + install deps + isolated data dir .data/
npm run dev            # Start the dev server at http://localhost:1920/admin/ (account admin/admin123)
npm run new myplugin   # Generate a plugin scaffold at plugins/openvideo-plugin-myplugin/
```

## Directory Layout

```
OpenVideoAPI-Dev/
├── server/              # OpenVideoAPI server code (cloned by setup, git-managed, pull anytime)
├── plugins/             # ★ Put all your plugins here (local packages, no npm publishing needed)
│   ├── openvideo-plugin-demo/       # Full example (1.1.0): routes / dynamic tables / events / cron / custom pages / static assets / admin tab / player overlay
│   └── openvideo-plugin-<yours>/    # generated by npm run new
├── tools/
│   ├── setup.js         # Initialization (clone server + install deps)
│   ├── dev.js           # Start the dev server
│   └── new-plugin.js    # Plugin scaffold generator
├── registry.json        # Local plugin market (file:// source, for demo purposes)
└── .data/               # Isolated data directory (never touches production data)
```

## Development Workflow

1. **Create a plugin**: `npm run new hello` generates `plugins/openvideo-plugin-hello/`
2. **Start**: `npm run dev` (default port 1920, isolated from production's 1919)
3. **Enable**: admin console → Plugin Management → enable `openvideo-plugin-hello`
4. **Develop**: edit any `.js`/`.json` file under `plugins/<pkg>/lib/` → **automatic hot reload** (no restart needed)
5. **Verify**: `/api/plugin/hello` (route), admin tab, player hook

## Dev Environment Features (server supported)

| Feature | Description |
| --- | --- |
| Configurable plugin directory | `OPENVIDEO_PLUGIN_DIR` points to this repo's `plugins/` |
| Isolated data directory | `OPENVIDEO_DATA_DIR` points to `.data/`, production data untouched |
| Hot reload | With `OPENVIDEO_DEV=1`, local plugin file changes trigger an automatic unload + reload (400ms debounce) |
| Local plugin market | `OPENVIDEO_PLUGIN_REGISTRY=file://../registry.json` (`file://` sources supported) |
| Crash auto-restart | If the dev server exits abnormally it is relaunched automatically after 3 seconds |
| Port isolation | Default 1920 (change with `node tools/dev.js 3000`) |

## Plugin Specification

A plugin is an **npm package** whose `package.json` `openvideoPlugin` field declares its capabilities:

```json
{
  "openvideoPlugin": {
    "name": "hello",
    "inject": ["store", "model", "app", "logger", "http"],
    "provide": [],
    "schema": [...],
    "client": {
      "admin": { "scripts": [...], "tabs": [{ "id": "hello", "title": "hello" }] },
      "player": { "scripts": [...], "replaces": false }
    }
  }
}
```

- Backend: `apply(ctx, config)`; `ctx` provides `router` / `store` / `model` (dynamic tables) / `app` (restart · version · config) / `logger` / `http` / `on`·`emit` / `provide`·`service`
- Frontend: `OpenVideoAdmin.registerTab` (admin tab), `OpenVideoPlayer.replace/onReady` (player)
- Full documentation: <https://doc.mbps.top/plugins/>

### Plugin Contract v2 (26.10.0+)

Since 26.10.0 the plugin contract v2 is fully additive (v1 plugins run unmodified):

- Manifest gains optional `deps` — an `openvideo` semver range plus a map of dependent plugins (auto-enabled recursively) — and `hooks` (`install`/`enable`/`disable`/`uninstall`/`update`).
- `ctx` adds `static` (serve package assets), `pages.register` (custom admin pages), `cron.every|at`, `settings` (plugin KV store), `logs`, `i18n`, `bus` (inter-plugin events), `model.namespace` (namespaced tables) and `http.request|text`; `ctx.on` now returns a cancel function.

See `PLUGIN-CONTRACT.md` in the [OpenVideoAPI main repo](https://github.com/yangyang8002/OpenVideoAPI) for the complete contract, and [plugins/openvideo-plugin-demo](plugins/openvideo-plugin-demo/) (v1.1.0) for a working v2 sample covering custom pages, static assets, cron, events and model namespaces.

## Submitting Your Plugin

When your plugin is ready:

1. Publish it to npm (package name convention: `openvideo-plugin-*`)
2. Open a PR against the [OpenVideoAPI repo](https://github.com/yangyang8002/OpenVideoAPI) to register it in `plugin-registry.json`
